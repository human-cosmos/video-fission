# Critical Points

- [ ] CP1: 后端 `http://127.0.0.1:8000/api/health` 可访问，且 `pipeline.ok` 与 `ffmpeg.ok` 均为 true。
- [ ] CP2: 前端 `http://127.0.0.1:5173` 可访问，工作台在真实浏览器中完成首次渲染。
- [ ] CP3: 顶栏可在「对话 / 视频创作 / 模型设置」之间切换，三个工作区均可见。
- [ ] CP4: 在视频创作页上传仓库测试视频、填写创作说明并启动任务，任务最终显示完成，播放器与 MP4 下载入口可见。

- [ ] CP6: 刷新页面后仍能加载该视频创作任务及已完成成片，验证持久化恢复。
- [ ] CP7: 最终成片 MP4 可从浏览器下载，文件非空且可被 ffprobe 解析。
